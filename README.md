# <img width="45" height="45" alt="mod-icon" src="https://github.com/user-attachments/assets/1674f736-33dc-4a1a-8659-20a4185c422f"/> Mute On Focus Loss Balatro Mod

Very simple **quality-of-life** mod that mutes the game when its window loses focus. Can be toggled in Options → Audio Settings. 
Support bunch of languages, such as: English, German, French, Russian, Simplified Chinese, and Japanese.
## Requirements
- Balatro (PC)
- Lovely Injector
- Steamodded

## Installation 
1. Install Lovely and Steamodded.
2. Download the latest relese of mod.
3. Extract the mod folder into yor Balatro Mods directory. (In Windows case: %AppData$\Balatro\Mods)
4. Launch Balatro.
5. Find the mod in the Mods menu.

## Compatibility
Was designed for Steamodded in mind, so compatibility with other audio mods is not garanteed (but should be fine), but you always can open new Issue ticket!
